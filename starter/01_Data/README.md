# Feed the team useful context.

Start with five inputs: what you sell, who buys, approved claims, three good examples, and the current goal. Record the source and date. Avoid an indiscriminate data dump.

- source-documents/: authoritative original material or a reference to its approved location.
- sanitised-conversations/: examples with personal details, customer identifiers and secrets removed unless their use is necessary and authorised.
- SOURCE_REGISTER.csv: which file is authoritative, how fresh it is, and what it may be used for.

Do not assume an uploaded file is a fact just because it exists. Label drafts, estimates and verified records. Retain unsuccessful sales conversations too; comparing wins and losses beats copying a script blindly.
